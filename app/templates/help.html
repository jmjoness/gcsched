Create Reservation Block:

Open a browser and go to "gcsched.smarterplot.com/"

click the Admin button

Enter "minister" for the password

Click on Set Blocks

Click on Add

Enter the date for appointments

Enter start time and number of reservations

For example: 4:00 pm, and 4 make 4 reservation blocks starting at 4:00, 4:30. 5:00 and 5:30

Click on Save

You will see the blocks that are currently available

Click on Home to leave

To see the blocks that have been created click on Set Blocks

Show Reserved Times

To see a list of people that have reserved times, click on Show List and select a date

For a member to reserve time:

Click on Reserve Time

Enter name and phone, select a date from the list of available dates, and select a time, then click on Save

To change a time:

Click on Change Time

Enter name and phone

The reservation should be displayed

Select a different date and/or time and click on Save
